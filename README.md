# Hi, I’m Tyler

## Featured project
[Reinforcement Learning Robustness SF](<https://github.com/TTong519/RobustnessSF>)

I used PyBullet and Stable Baselines 3 to train a RL model to control a robotic arm. I then tested the robustness of the RL model in a variety of situations.

## Tools I’ve used
- Data Structures and Algorithms: I have hand-implemented a large set of popular data structures and algorithms. These include Red-Black Trees, A*, Radix Sort, Quick Sort, and others.
- Neural Networks / Basic ML: I have also hand-implemented some basic ML tools, like perceptrons and neural networks. I have also implemented backpropagation on neural networks and perceptrons, genetic learning, as well as basic hill climbing optimization.
- Reinforcement Learning: I have some experience in reinforcement learning, and have implemented algorithms such as Q learning and Deep Q learning.

## What I’m learning next
I am currently learning about SQL, servers, and ML techniques.
